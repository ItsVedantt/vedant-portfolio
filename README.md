# Vedant Nasare — Cyberpunk Game Portfolio

Resume-based static Astro portfolio with a responsive game/pause-menu interface.

## Run
npm install
npm run dev

## Build
npm run build

## Customize
Edit `src/data/config.js`.

## Included
- 9 interactive screens
- 3 supplied photos
- Resume-grounded content
- Instagram: @ordinaryboy_vedant
- GitHub: ItsVedantt
- Phone number and resume CTA removed from the website
- Live clock, minimap, progress HUD, pause menu
- Mouse, touch-friendly controls and keyboard navigation
- Responsive layouts for desktop, tablet, mobile portrait and mobile landscape
- Reduced-motion support
